# samir-khadka.com.np

My personal portfolio — live at https://samir-khadka.com.np.

A static site built with HTML, CSS and JavaScript,
hosted on GitHub Pages with a custom domain (CNAME).
One scrolling page (home, about, skills, projects, experience, education,
achievements, interests, contact) with a dark glass theme and a light toggle.
projects.html, interests.html and contact.html forward to the matching section.

Files: index.html, style.css, script.js, assets/, plus the three forwarding pages.
Icons: Font Awesome Free 6.4 (icons CC BY 4.0, fonts SIL OFL 1.1, code MIT), loaded from cdnjs.
